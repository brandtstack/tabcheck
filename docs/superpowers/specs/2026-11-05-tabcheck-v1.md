# tabcheck v1

> **Request (Adrian, 2026-11-05):** first public project, "your recommendations on all, go ahead".
> The recommendations he accepted: name `tabcheck`, MIT, public in the `brandtstack` org and pinned on
> his profile, v1 = `check` + `sheet` + `export`, published to the public npm registry under an
> unscoped name.

## What it is

A CLI that answers one question most icon tools never ask: **does this favicon actually show up on a
browser tab, light and dark?** It renders the SVG in real Chromium (the rasteriser a tab strip uses),
measures the pixels, and fails CI when the mark disappears. Then it exports the whole icon set from
the same master, all or nothing.

```sh
npx tabcheck check icon.svg                # gates; exit 1 on a fail
npx tabcheck sheet concepts/ --out sheet.png   # every size, light + dark tabs, 16 px ×8
npx tabcheck export icon.svg --plate '#0f1626' --name Tilde --out public/
```

**Source:** icon-kit, an unpublished toolkit (865 lines, built 2026-10-22, used on brandtstack, tilde and
buvik). tabcheck is that kit made fit for strangers, not a rewrite.

## Scope

**In v1**

| Command | Does | From the kit |
| --- | --- | --- |
| `check <svg…>` | Gates: `xml`, `no-text`/`no-foreign`/`no-raster`/`no-external`, `viewbox`, `blank`, `contrast` (≥75 % of opaque pixels at ≥3:1 on the active tab, light and dark), `safe-zone` (info: px size that fits a maskable circle), `bbox` (warn). `--plate` gates installed-icon grounds. `--json` for machines. | `check.ts` |
| `sheet <dir\|svg…> --out` | Contact sheet, one row per concept: 180/48/32, 16 px in a mock tab, 16 px ×8, light and dark; `--plate` adds iOS + Android masks | `render-sheet.ts` |
| `export <master> --plate --name --out` | `favicon.svg`, `favicon.ico` (16/32/48), `apple-touch-icon.png`, `icon-192/512.png`, `icon-maskable-512.png`, `manifest-icons.json`. Re-runs `check` first; writes the whole set or nothing | `export.ts` minus the share card |

**Out of v1:** the `og-card.png` share card (needs `lettermark` + vendored fonts), `lettermark`,
`shape`, a GitHub Action wrapper (v1.1: a `uses: brandtstack/tabcheck@v1` that runs `check`).

**Exit codes:** 0 pass, 1 a gate failed, 2 usage or environment error (no browser, unreadable file).

## Decisions

1. **Ships compiled JS.** The kit runs `.ts` through Node's type stripping, and Node refuses to strip
   types for files under `node_modules`. So `src/*.ts` → `tsc` → `dist/*.js`, `bin` points at
   `dist`. `engines: node >=22`.
2. **Browser resolution, in order:** `--browser <path>` / `TABCHECK_BROWSER`, then the user's
   installed Chrome (`channel: 'chrome'`), then Playwright's Chromium cache. None found → exit 2 with
   the one-line install command. `playwright-core` stays the only browser dependency; no 150 MB
   download on `npm install`.
3. **Untrusted SVG is only ever an image.** Every render goes through `<img>`/canvas from a blob, so
   SVG script never runs, and the page blocks all network requests (`page.route('**', abort)`), so
   a hostile SVG cannot fetch anything. A test proves both: a fixture with `<script>` and an external
   `href` must be refused by the static gates *and* must not reach a local listener.
4. **Tab colours are named defaults, overridable.** `--light '#ffffff,#dee1e6' --dark
   '#202124,#35363a'`: the active tab is gated, the inactive strip warns. ⚠️ **Unverified, inherited
   from the kit (2026-10-22):** these are Chrome's colours. Re-measure in current stable Chrome
   before v0.1.0 and write the date into the README.
5. **The gates are proven red.** The kit's `gates` fixtures (`good`, `scheme-switch`, `bad-xml`,
   `blank`, `text`, `low-contrast`) become Vitest cases with a known answer each, plus the
   plate-scheme rows and the new hostile-SVG fixture. A control that passes is a broken gate.
6. **Deps exact-pinned** (`playwright-core 1.64.1`, `opentype.js` not needed without lettermark,
   `typescript`, `vitest`). A consumer gets exactly what was tested.
7. **Public repo, fresh history.** New repo `brandtstack/tabcheck`, first commit from a clean
   `git init`, noreply identity. Nothing copied that names private services: the kit README's
   fixture and font notes mention a private project and are rewritten, not copied.

## CI and release

- **CI on GitHub's runners only** (`ubuntu-latest`). The org's runner group already refuses public
  repos (`allows_public_repositories: false`, checked 2026-11-05); the workflow never names a
  self-hosted label. Steps: `npm ci` → install `chromium-headless-shell` (cached) → `npm run
  verify` (typecheck + build + tests). Plus a smoke job: `npm pack`, install the tarball in a temp
  dir, run `npx tabcheck check fixtures/good.svg`, which is the only proof the published shape works.
- **Renovate:** extends `github>brandtstack/workspace-ci` (public).
- **Release:** pushing a `v*` tag runs `npm publish --provenance` through npm **trusted publishing**
  (OIDC, no token stored). ⚠️ **Adrian's step:** create/log in to the npm account, publish `0.1.0`
  once by hand (or claim the name), and register `brandtstack/tabcheck` as the trusted publisher.
  Claude does not create accounts or handle the npm password.
